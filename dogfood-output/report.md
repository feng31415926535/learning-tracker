## 三、详细问题列表

### ISSUE-001: 缺少图片 alt 属性

| 字段 | 值 |
|------|-----|
| **严重程度** | medium |
| **类别** | accessibility |
| **URL** | http://localhost:5173 |
| **复现视频** | N/A |

**描述**

应用中存在装饰性图片（如 logo 图标、状态图标等）但未提供 `alt` 属性或 `aria-label`。虽然 SVG 图标通过父元素的文字标签提供了一定的上下文，但对于纯图片元素缺乏替代文本，影响屏幕阅读器用户的理解。

**复现步骤**

1. 打开应用首页
2. 使用浏览器开发者工具检查 logo 图标和状态图标
3. 观察到 `<img>` 或 `<svg>` 元素缺少 `alt` 或 `aria-label` 属性

**修复建议**

- 为所有功能性图标添加 `aria-label` 属性
- 装饰性图标添加 `aria-hidden="true"`
- 确保图片元素有适当的 `alt` 文本

### ISSUE-002: 表单输入框缺少关联标签

| 字段 | 值 |
|------|-----|
| **严重程度** | medium |
| **类别** | accessibility |
| **URL** | http://localhost:5173 |
| **复现视频** | N/A |

**描述**

在导入计划弹窗中，输入框虽然有 `<label>` 元素，但未使用 `for` 属性与输入框关联，导致屏幕阅读器可能无法正确读取标签。这影响表单的可访问性。

**复现步骤**

1. 点击"导入第一个计划"按钮
2. 检查表单输入框与标签的关联
3. 观察到 `<label>` 元素未使用 `for` 属性指向输入框 `id`

**修复建议**

```html
<label for="plan-name">计划名称</label>
<input id="plan-name" v-model="planName" type="text" />
```

### ISSUE-003: 颜色对比度不足

| 字段 | 值 |
|------|-----|
| **严重程度** | medium |
| **类别** | accessibility |
| **URL** | http://localhost:5173 |
| **复现视频** | N/A |

**描述**

部分文字颜色与背景的对比度未达到 WCAG AA 标准（4.5:1）。特别是：
- `--text-muted` 颜色（`rgba(250, 250, 250, 0.35)`）在深色背景上对比度较低
- 状态标签（如"必看"、"倍速"）的文字与背景对比度可能不足

**修复建议**

- 提高 `--text-muted` 的不透明度至至少 0.5
- 确保所有状态标签文字对比度达到 4.5:1

### ISSUE-005: 错误提示使用 alert()

| 字段 | 值 |
|------|-----|
| **严重程度** | high |
| **类别** | ux |
| **URL** | http://localhost:5173 |
| **复现视频** | N/A |

**描述**

在 `ImportModal.vue` 和 `LLMConfigModal.vue` 中，表单验证错误使用 `alert()` 弹窗提示，这是一种过时的用户体验模式，会打断用户操作流程，且在视觉上与应用设计风格不一致。

**复现步骤**

1. 打开导入计划弹窗
2. 不填写任何内容直接点击"导入"
3. 观察到浏览器原生 alert 弹窗

**修复建议**

- 使用内联错误提示或 Toast 通知组件
- 在表单字段下方显示错误信息
- 添加适当的 ARIA 属性通知屏幕阅读器

### ISSUE-006: 缺少加载状态指示器

| 字段 | 值 |
|------|-----|
| **严重程度** | high |
| **类别** | ux |
| **URL** | http://localhost:5173 |
| **复现视频** | N/A |

**描述**

### ISSUE-008: 缺少 SEO 元标签

| 字段 | 值 |
|------|-----|
| **严重程度** | low |
| **类别** | seo |
| **URL** | http://localhost:5173 |
| **复现视频** | N/A |

**描述**

`index.html` 中缺少必要的 SEO 元标签，如 `<meta name="description">`、Open Graph 标签等。虽然这是一个本地应用，但如果部署到公网，SEO 优化会受限。

**修复建议**

```html
<meta name="description" content="Learning Tracker - 学习进度追踪工具">
<meta property="og:title" content="Learning Tracker">
<meta property="og:description" content="追踪你的学习进度，支持任务状态管理、星级评分和学后测试">
```

### ISSUE-009: localStorage 数据无加密

| 字段 | 值 |
|------|-----|
| **严重程度** | low |
| **类别** | best-practices |
| **URL** | http://localhost:5173 |
| **复现视频** | N/A |

**描述**

LLM API Key 存储在 localStorage 中，虽然应用说明了"仅存储在本地浏览器中"，但 localStorage 数据可被同域脚本读取，存在潜在安全风险。

**修复建议**

- 考虑使用 `SubtleCrypto` API 对敏感数据进行加密存储
- 或在每次会话时要求用户重新输入 API Key

## 四、优点总结

### 🎨 设计质量
- **Apple 级设计质感**：暗色/亮色主题切换流畅，配色方案专业（Amber Gold + Deep Indigo）
- **精细的视觉细节**：噪点纹理背景、玻璃态效果、微动画反馈
- **一致的设计语言**：统一的圆角、间距、阴影系统

### 📊 功能完整性
- **核心功能完备**：计划导入、任务管理、进度统计、学后测试
- **智能学习建议**：根据完成进度动态生成学习建议
- **多 LLM 支持**：集成 8 个主流 LLM 提供商，切换自动更新模型列表

### 💻 代码质量
- **TypeScript 类型安全**：完整的类型定义，无 `any` 使用
- **组件化架构**：职责分明，复用性强
- **状态管理规范**：Pinia store 结构清晰，使用 Composition API

### 🔧 技术实现
- **数据持久化**：使用 `@vueuse/core` 的 `useLocalStorage` 实现自动持久化
- **响应式设计**：适配桌面和移动端
- **性能优化**：Vite 构建，按需加载，无冗余依赖

## 五、优化建议

### 高优先级

1. **改进错误提示方式**
   - 创建 Toast 通知组件替代 `alert()`
   - 在表单字段下方显示内联错误信息
   - 添加适当的 ARIA 属性

2. **增强加载状态反馈**
   - 为所有异步操作添加 loading 状态
   - 使用骨架屏提升感知性能
   - 防止重复提交

3. **提升可访问性**
   - 为所有表单输入框添加正确的标签关联
   - 提高文字对比度至 WCAG AA 标准
   - 增强键盘导航支持

### 中优先级

4. **添加 PWA 支持**
   - 配置 Service Worker 实现离线访问
   - 添加 Web App Manifest 支持安装到主屏幕

5. **增强安全性**
   - 考虑对 API Key 进行加密存储
   - 添加 CSP (Content Security Policy) 头

6. **完善测试覆盖**
   - 配置 Vitest 单元测试
   - 为核心业务逻辑编写测试用例

### 低优先级

7. **SEO 优化**
   - 添加必要的 meta 标签
   - 配置 Open Graph 标签

8. **国际化支持**
   - 使用 Vue I18n 支持多语言
   - 抽取所有硬编码文本

9. **性能监控**
   - 集成错误追踪（如 Sentry）
   - 添加性能指标收集
