## 常见问题排查

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 端口 5173 被占用 | 其他进程占用端口 | 使用 `npx vite --port 3000` 指定其他端口 |
| `npm install` 失败 | 网络问题 | 使用 `npm install --registry=https://registry.npmmirror.com` |
| 页面空白 | 编译错误 | 检查终端输出，查看浏览器 Console |
| 导入 JSON 失败 | 格式错误 | 对照示例 JSON 检查字段名和格式 |
| 主题切换无效 | CSS 变量未应用 | 检查 `data-theme` 属性是否正确设置 |
